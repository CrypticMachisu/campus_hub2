# API Needs

## Overview

Group 7 is developing a Clubs and Events application. As part of the project, our application will integrate with Group 6's farming application and Group 8's marketplace application.

The purpose of these integrations is to allow the different applications to exchange relevant information and services through APIs.

---

## Group 6 — Farming Application

### Information We Consume from Group 6

Our application will consume the following information from Group 6's farming application:

1. **Aspiring Farmer Details**
   - Farmer/member ID
   - Name
   - Email
   - Other relevant personal details

2. **Location**
   - Farmer/farming location

3. **Farming Products**
   - Product name
   - Product category
   - Product description
   - Other relevant product details

4. **Inventory Details**
   - Available products
   - Quantity/stock
   - Product availability

### Information Group 6 Consumes from Us

- To be confirmed with Group 6 based on the agreed API requirements and API contract.

---

## Group 8 — Marketplace Application

### Information We Consume from Group 8

Our application will consume the following information/services from Group 8's marketplace application:

1. **Marketing Places**
   - Marketing places where clubs can promote their activities and products, such as flea markets.

2. **Club and Event Details**
   - Relevant club information
   - Event information and details

3. **Access to Clubs During Marketing Events**
   - Information or functionality that allows clubs or members to access or participate in marketing events.

### Information Group 8 Consumes from Us

- To be confirmed with Group 8 based on the agreed API requirements and API contract.

---

## API Integration Requirements

Before implementation, the groups will need to agree on:

- API endpoints
- Request and response formats
- Required data fields
- Authentication requirements
- Error handling
- Data validation
- API availability and limitations

---

## Reflection

The meetings helped us understand how Group 7's Clubs and Events application can integrate with the applications developed by Groups 6 and 8. We identified the main information and services that our application needs to consume from each group and discussed the role our API will play in providing information to the partner applications.

We also learned that successful API integration requires clear communication between groups. The exact endpoints, data fields, request and response formats, and responsibilities need to be agreed upon before implementation. The meetings also showed us that we should confirm what information is actually available through each group's API rather than making assumptions about the data that can be exchanged.
