CampusHub API (2.0.0)

Download OpenAPI specification:

REST API for the CampusHub clubs-and-events app. Clubs and events can be read without signing in. Creating or changing data requires a bearer token from POST /auth/login. All responses are JSON, except that unknown URLs return Express's default HTML 404 page.
