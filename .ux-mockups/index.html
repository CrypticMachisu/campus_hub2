Loading, without the wait.

Four runnable directions built on the real Discover and member-workspace structures. A, B and C explore separate balances of perceived-performance loading, GSAP choreography and operational honesty. D pairs B's editorial setting with C's independent section boundaries.

No production code was changed. The mockups use the installed GSAP version (3.15.1) via CDN, the real Signal tokens, self-hosted fonts and actual campus imagery.

How to test

  1. Open a direction and let it settle.
  2. Press Cold load and watch when the skeleton appears.
  3. Press Warm cache; confirm there is no skeleton flash.
  4. Press Optimistic / Flip. Alt-click it to see rollback.
  5. Press Empty / Error repeatedly to cycle the hand-off states.

Run it

Both direct file opening and the Vite dev server work. If you use Vite, open http://127.0.0.1:5173/.ux-mockups/index.html. The mockups also run from the filesystem; GSAP loads from the same pinned 3.15.1 CDN release.

Direction C also has two embedded tests: Post an update shows a locked-width inline spinner, and Export roster runs a determinate long task. In Direction D, Empty / Error only replaces the club plate, and Save the edition runs the determinate PDF task from the desk rail.
