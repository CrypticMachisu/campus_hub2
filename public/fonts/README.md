# Bundled fonts

Space Grotesk, IBM Plex Sans and IBM Plex Mono are bundled so the app renders its
intended typography without a network request to Google Fonts.

All three families are licensed under the SIL Open Font License 1.1:
<https://openfontlicense.org>

The `.woff2` files here are the Latin subsets downloaded from Google Fonts. The
weights match what `src/styles/theme.css` declares.
